01 / DATA PROCESSING & REPORT AUTOMATION

ATM log reporting

Different log formats. One consistent report.

The task

ATM journals from different sources use different formats. Reviewing them is easier when transaction and event records share a consistent structure.

My contribution

Built a Python tool that parses JRN and NCR logs, normalizes their records, and produces Excel and CSV reports alongside a searchable SQLite history.

Consistent output

Separated transactions, events, and summaries into clear report views.

Traceable records

Kept source-file references with processed records to support review and troubleshooting.

Repeat-run handling

Used file hashes to avoid inserting an already processed file into the database again.

WHAT THE TOOL PROVIDES

A repeatable path from raw logs to reports and stored records, with options for report-only, database-only, or combined output.

02 / VB6 → PYTHON MIGRATION

Daily transaction reporting

Preserve the rules. Improve the structure.

The task

An existing VB6 reporting workflow needed a Python implementation that retained its established report logic and outputs.

My contribution

Converted the workflow into a modular Python application, separating database access, report coordination, and file export. The program retrieves records for a selected reporting date and generates formatted Excel and CSV outputs.

Legacy behavior

Preserved the established reporting logic while reorganizing the implementation into focused modules.

Readable reports

Generated formatted reports with debit, credit, and transaction summaries.

Output protection

Added a check for an existing report to avoid overwriting previously generated output.

WHAT THE TOOL PROVIDES

A Python reporting workflow that retains the legacy behavior and makes its processing stages easier to follow and maintain.

03 / VB6 → PYTHON MIGRATION

MT940 statement generation

From transaction records to statement files.

The task

A legacy statement-generation workflow combined record retrieval, account processing, file formatting, and delivery handling.

My contribution

Migrated the workflow from VB6 to Python, retaining its existing behavior while separating database access, statement generation, and email-delivery handling into dedicated modules.

Structured statements

Generated MT940 text statements from the records for a selected processing date.

Duplicate safeguards

Checked processing status and existing output before repeating work.

Operational clarity

Added progress messages and documented the setup, execution flow, and troubleshooting steps.

WHAT THE TOOL PROVIDES

A modular statement-generation tool with repeat-run safeguards and documented operation. Email delivery remains dependent on the configured mail service.
